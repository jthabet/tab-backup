# Firefox Add-ons listing

Text and screenshots for https://addons.mozilla.org/developers/addon/tab-backup/edit
(default locale: en-GB).

## Summary

Back up the tabs in your window to a file or a synced bookmark folder, then
preview and restore them whenever you need.

## Description

Paste as is. Firefox Add-ons accepts the `<b>`, `<ul>` and `<li>` tags below.

```html
Back up every tab in the current window in one click, and bring them back whenever you need them.

<b>Back up</b>
<ul>
<li>Save to a file: JSON, Markdown, plain text, or an HTML bookmarks file you can import into any browser.</li>
<li>Or save to a bookmark folder that Firefox Sync carries to your other devices, including Firefox for Android and iOS.</li>
<li>Name your files with date, time and tab count patterns.</li>
</ul>

<b>Restore</b>
<ul>
<li>Preview a backup before anything opens, and choose which tabs come back.</li>
<li>Tabs that are already open are left out automatically.</li>
<li>Restore from any backup format, or straight from a bookmark backup.</li>
</ul>

<b>Private by design</b>
Tab Backup doesn't collect or send any data. Your backups stay in your downloads folder or your own bookmarks. Bookmark access is only requested if you turn on bookmark backups.

Source code: https://github.com/jthabet/tab-backup
Folder icon by Smashicons on Freepik: https://www.freepik.com/icon/folder_10773696
```
